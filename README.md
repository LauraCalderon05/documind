# DocuMind – Sistema Inteligente de Gestión y Análisis Documental

DocuMind es una aplicación web desarrollada para la gestión, organización y análisis de documentos empresariales.

El sistema permite almacenar documentos en repositorios y carpetas, cargar archivos en formatos PDF, DOCX y TXT, extraer su contenido, procesarlo y obtener información relevante como clasificación, resumen y datos estructurados.

También permite buscar documentos por contenido y realizar consultas sobre la información almacenada.
## Funcionalidades

- Registro e inicio de sesión de usuarios.
- Gestión de usuarios y roles.
- Creación y administración de repositorios.
- Creación y administración de carpetas.
- Carga de documentos PDF, DOCX y TXT.
- Validación de archivos.
- Extracción de texto de los documentos.
- Clasificación de documentos.
- Generación de resúmenes.
- Extracción de información relevante según el tipo de documento.
- Consulta y descarga de documentos.
- Búsqueda de documentos por contenido.
- Consultas en lenguaje natural.
- Registro de errores de procesamiento.
- Seguimiento del estado de procesamiento.
- Visualización de estadísticas mediante un dashboard.
